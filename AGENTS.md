# Kinga Marchlewska — Portfolio

Static portfolio site: Next.js (App Router) + React 19 + Tailwind CSS v4.
Originally generated by Figma Make; the Figma/Payload CMS backend has been
removed, and the site is deployed on Vercel.

## Commands

- `pnpm install` — install dependencies
- `pnpm dev` — local dev server at http://localhost:3000
- `pnpm build` — production build (must pass before deploying)

## Structure

- `src/app/(frontend)/` — routes (`page.tsx` per URL); `layout.tsx` is the root layout
- `src/components/portfolio/` — page components; all site content (text, project
  data, image paths) lives directly in these files
- `public/imports/` — images and the CV PDF, referenced as `/imports/<file>`
- `.figma/make/site.json` — site settings read by `src/lib/make-site-settings.ts`

## Notes

- All routes are statically prerendered; keep them static.
- Use `SiteImage` (wraps `next/image`) for images. Remote image hosts must be
  allowed in `images.remotePatterns` in `next.config.ts`.
- The contact form (`src/app/(frontend)/contact/actions.ts`) sends mail via
  Resend and needs the `RESEND_API_KEY` environment variable on the server.
